# System libraries and fonts the Playwright browsers link against on
# ubuntu-24.04-x64.
#
# This is the `tools`, `chromium` and `webkit` arrays of Playwright 1.65.0's own
# dependency table for ubuntu24.04-x64, deduplicated and sorted. It is a file
# here instead of a `playwright install --with-deps` call because that call also
# lets apt resolve every Recommends: on 2026-11-18 that was 181 packages and
# 125 MB, and a slow mirror turned it into fourteen minutes of `Get:` lines
# until the 15-minute job cap cancelled the job before a single test ran.
# `./task browser-deps` installs this list with `--no-install-recommends`.
#
# `tools` is not optional: it carries the fonts, and the visual baselines bake
# their glyphs in. Leaving it out kept the browsers launchable but swapped the
# two symbol controls on the scoreboard for fallback tofu, which the Linux
# baseline diffed at 91-525 pixels on all three viewports (PR #77, 2026-11-18).
#
# Bump it together with the Playwright pin in deps.lock: the arrays live in
# node_modules/playwright-core/lib/coreBundle.js under "ubuntu24.04-x64".
# The suite drives chromium and webkit only (e2e/browsers.ts), so the firefox
# system libraries are deliberately absent; `pnpm exec playwright install`
# still downloads the pinned firefox build that `./task deps-check` requires.
