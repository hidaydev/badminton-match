# System packages the Playwright browsers need on ubuntu-24.04-x64.
#
# The `tools`, `chromium`, `firefox` and `webkit` arrays of the Playwright
# build pinned in deps.lock, deduplicated and sorted. They live in a file here
# instead of being asked for by `playwright install --with-deps` because that
# call is one unbounded apt run: on 2026-11-18 a slow mirror spent 13m47s
# inside it and the 15-minute job cap cancelled the job before a single test
# ran.
#
# All four groups are kept, firefox included, because `--with-deps` reads the
# same table and the resolved set is what the committed visual baselines were
# recorded against. Narrowing it is not free: dropping the firefox group
# changed the font fallback enough that the scoreboard`s `\u26f6` control
# rendered as a hollow box and every visual test failed on 91 pixels. Recommends
# stay on for the same reason: the closure is 181 packages and 117 fonts, and
# without Recommends 8 fonts remain.
#
# Bump this together with the Playwright pin: the arrays live in
# node_modules/playwright-core/lib/coreBundle.js under "ubuntu24.04-x64".
#
# `./task browser-deps` installs this list and caps the whole apt run.
